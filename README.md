# FitPlan Pro

برنامج لياقة بدنية احترافي يدمج:
- خطة تدريب أسبوعية
- لوحة تحكم يومية
- متابعة الماء والسعرات
- نظام التزام ونجاح أسبوعي
- نصائح تغذية وراحة

## التشغيل

### طريقة 1: المتصفح مباشرة
افتح ملف `index.html` في المتصفح.

### طريقة 2: خادم محلي
```bash
python -m http.server 8000
```
ثم افتح:
```text
http://localhost:8000
```

## الملفات
- `index.html` — الصفحة الرئيسية
- `styles.css` — تصميم واجهة التطبيق
- `script.js` — منطق الخطة والتتبع

## ملامح البرنامج
- جدول أسبوعي كامل
- تتبع جلسات التدريب
- مؤشرات الماء والسعرات
- إحصائيات الالتزام
- واجهة عربية احترافية
- حفظ تلقائي في المتصفح باستخدام `localStorage`

## نصائح للاستخدام
- التزم بـ 4 جلسات تدريب في الأسبوع
- اشرب 2–2.5 لتر ماء يوميًا
- تناول بروتين في كل وجبة
- احرص على النوم بنظام منتظم
- زِد التمارين تدريجيًا أسبوعيًا

## لملف Python (اختياري)
إذا كنت تريد نسخة Python إضافية للتتبع، يمكنني تجهيزها لك أيضاً.
